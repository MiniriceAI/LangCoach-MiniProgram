## 图标设计建议

- 主色调: #4A90D9 (蓝色)
- 未选中颜色: #999999 (灰色)
- 选中颜色: #4A90D9 (蓝色)
- 风格: 线性图标，简洁现代
- 格式: PNG，支持透明背景
